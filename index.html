Ten systems libraries, built from scratch.

Each one is TypeScript with no third-party runtime code: the feature flags, the job queue, the search index and the rest are written against Node's own modules. Every card below opens a working demo — the buttons hit the real library, not a mock.

  • 190 tests on Node's built-in runner
  • zero runtime dependencies
  • strict TypeScript
  • MIT licensed

  • 01 Beacon

    Counters and histograms rendered in Prometheus text format, from a scrape you can trigger.

    Live demo ↗ Source

  • 02 Cordon

    Token-bucket rate limiting that answers with a proper Retry-After instead of dropping requests.

    Live demo ↗ Source

  • 03 Crucible

    An expression language with its own lexer, parser and evaluator — no eval() anywhere.

    Live demo ↗ Source

  • 04 Relay

    Webhook delivery with HMAC signatures, retries and a dead letter, and no requests to private addresses.

    Live demo ↗ Source

  • 05 Sift

    Full-text search with a positional index and BM25 ranking, including phrase and prefix matching.

    Live demo ↗ Source

  • 06 Aperture

    scrypt password hashing, session tokens stored only as hashes, and RFC 6238 one-time codes.

    Live demo ↗ Source

  • 07 Atlas

    Event-sourced documents where a stale write is rejected instead of quietly overwriting someone.

    Live demo ↗ Source

  • 08 Ledger

    Double-entry accounting on integer minor units, refusing any entry that would unbalance the books.

    Live demo ↗ Source

  • 09 Ratchet

    A job queue with leases, exponential backoff and a dead letter, so a poisoned job never loops.

    Live demo ↗ Source

  • 10 Quorum

    Feature flags bucketed by a hash of flag and subject, so raising a rollout can only add people.

    Live demo ↗ Source

Demos run on Render's free tier, so the first visit to a sleeping app can take a few seconds to wake up. Source for all ten lives at github.com/MotherTheresa64.
